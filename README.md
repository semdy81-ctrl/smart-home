# Умный дом (демо) для Android 5.1

Демо-версия: все экраны и кнопки работают, но к реальным устройствам приложение пока не подключено.
Минимальная версия Android: 5.1 (API 22). Сервисы Google не используются.

## Как получить APK (онлайн, через GitHub)
1. Создайте аккаунт на github.com и новый приватный репозиторий (кнопка New).
2. Распакуйте архив, в репозитории нажмите «uploading an existing file» и перетащите в окно содержимое папки (вместе с папкой .github), затем Commit changes.
3. Откройте вкладку Actions, дождитесь зелёной галочки (около 5 минут), откройте сборку и скачайте файл smart-home-apk внизу страницы.
4. Распакуйте скачанный zip, получится app-debug.apk. Скопируйте его на планшет и откройте (в настройках разрешите установку из неизвестных источников).

Если вкладка Actions пуста, значит папка .github не загрузилась: в репозитории нажмите Add file, Create new file, в имени файла наберите .github/workflows/build.yml и вставьте туда содержимое файла build.yml из архива.
